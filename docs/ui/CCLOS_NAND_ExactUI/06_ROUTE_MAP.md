# Route and behavior map

## Main destinations

- **Home** → existing CCLOS Home services. Home labels such as `My Collection`, `Marketplace`, `Watch TV` and `Achievements` stay as approved.
- **My Games** → existing collection/library/favorites/recent/disc functions.
- **Media** → existing Media Center/player and supported source discovery.
- **Store** → existing CCLOS Marketplace catalog/manifest backend.
- **Downloads** → existing queue, segmented/single download, resume, extraction and install flow.
- **Settings** → existing settings plus only verified system/NAND actions behind capability and safety gates.

## Approved submenu targets

1. Game Detail — selected-title data and verified Play/Details/Achievements/saves/screenshots/add-ons/title-update bindings only where services actually exist.
2. Download Detail — real queue item/progress/speed/ETA/storage; pause/resume/cancel/retry through existing command paths.
3. Network Settings — verified network/system-bridge data; screenshot IP/DNS/speed values are fixtures only.
4. Interface Customization — expose only settings the current runtime can actually support.
5. Live TV Guide — bind existing Watch TV/media services; fictional guide content is layout-only.
6. Movies/Media Browse — real local/network sources and metadata.
7. DLC/Title Updates — existing DLC/TU discovery/install semantics; do not fabricate commerce.

Every pre-existing CCLOS destination not represented by an approved redesigned PNG remains reachable through an inherited-page bridge until the owner explicitly approves its replacement.
